# Flask CRUD API with TDD

This is a backend project built using Python and Flask. It provides a RESTful API to manage tasks and comments. The project follows **Test-Driven Development (TDD)** principles to ensure code reliability.

# Features
 **CRUD Operations:** Create, Read, Update, and Delete comments.
 **RESTful API:** Standard HTTP methods (GET, POST, PUT, DELETE).
 **Automated Testing:** Includes a test suite using Python's built-in `unittest`.
 **Frontend Integration:** Includes a basic HTML/JS frontend to interact with the API.

# Tech Stack
 **Language:** Python
 **Framework:** Flask
 **Testing:** unittest
